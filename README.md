# SADAP — Medical Web Application

> A full-stack clinic management platform serving **10,000+ patients** at Sadap Clinic, Aktau, Kazakhstan.

🌐 **Live:** [sadap.kz](https://sadap.kz/)

---

## Overview

SADAP is a comprehensive medical web application built to modernize patient care and clinic operations at Sadap Clinic. It streamlines everything from appointment scheduling to access to medical records — all in one platform.

---

## Features

### 🗓 Multi-Step Appointment Booking
Guided booking flow that allows patients to select a service, choose a specialist, pick an available time slot, and confirm — reducing friction and front-desk load.

### 👨‍⚕️ Doctor Directory
Searchable and filterable catalog of physicians organized by specialty, helping patients quickly find the right doctor for their needs.

### 🧾 Patient Portal
Personal dashboard where patients can view and manage their medical records, track upcoming and past appointments, and stay informed about their healthcare.

### 🏥 Services Catalog
Detailed listing of all clinic offerings, including:
- **Diagnostics**
- **Surgical procedures**
- **Laboratory analysis**
- **Home visits**
